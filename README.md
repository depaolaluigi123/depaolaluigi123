## 👨‍💻 Chi sono

Sono **Luigi De Paola**, laureato in **Ingegneria Informatica** all'[Università della Calabria](https://www.unical.it/) (UniCal).

Mi appassiono allo sviluppo software end-to-end: dal backend con Java e Python, alle interfacce web con Angular, fino all'infrastruttura con Docker e Linux. Conosco la **programmazione orientata agli oggetti** e la **programmazione concorrente**; curo molto i software che realizzo, ricorrendo ai **pattern di progettazione** e ai principi dell'**ingegneria del software** per mantenerli chiari, manutenibili e robusti.

---

## 🎓 Formazione

📚 **Diploma di Liceo Scientifico**

🎓 **Laurea in Ingegneria Informatica**, con tesi di laurea svolta in tirocinio presso l'azienda [**Artèmat**](https://www.artemat.it)
  - **Notification Platform: una piattaforma centralizzata per la gestione di notifiche multicanale in ambienti enterprise** - piattaforma middleware che disaccoppia i servizi applicativi dalla logica di invio delle notifiche (e-mail, Slack, Telegram, webhook, SSE, code di messaggi), ricevendo gli eventi via API REST o Apache Kafka e orchestrandone l'instradamento in base a configurazioni e template persistiti su database; integra matching gerarchico delle regole di instradamento, retry con backoff esponenziale, scheduling delle notifiche programmate, tracciabilità e idempotenza dei flussi, pannello di controllo per amministratori e supporto LLM per la gestione dei template.
